# Mi Plan de Deudas

Aplicación web para registrar deudas, comparar estrategias de pago y administrar presupuestos y recordatorios.

El código de la aplicación está en `dist/`. Los datos financieros se guardan localmente en el navegador o dispositivo; esta versión no sincroniza automáticamente entre dispositivos. Los respaldos pueden contener datos financieros sin cifrar.

Esta copia corresponde al código fuente de la versión publicada 12 del sitio, con el selector de moneda y las ayudas educativas. No incluye deudas personales ni credenciales.

Las pruebas ejecutadas para esta transferencia comprenden comprobaciones de sintaxis JavaScript, recursos del manifiesto y pruebas automatizadas de finanzas, selector de moneda, ayudas, recordatorios y respaldo con datos simulados. Las pruebas de interfaz se ejecutaron con DOM simulado.
